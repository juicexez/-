# 🤖 Telegram Бот - Переводчик и Помощник с Английским

Многофункциональный бот для изучения английского языка: переводчик + помощник с домашними заданиями. Идеально подходит для школьников и студентов!

## ✨ Возможности

### 🔤 ПЕРЕВОДЧИК
- 📝 **Текстовый перевод** - мгновенный перевод текстовых сообщений
- 📷 **Перевод с фото** - распознавание текста (OCR) на изображениях и перевод
- 🎤 **Перевод голосовых** - распознавание речи из голосовых сообщений и перевод
- ⚡ **Быстрая работа** - оптимизирован для максимальной скорости
- 🎯 **Точный перевод** - использует Google Translate API

### 📚 ПОМОЩНИК С ДОМАШНИМИ ЗАДАНИЯМИ
- ✏️ **Грамматические упражнения** - помощь с временами, формами глаголов, выбором правильного варианта
- 📖 **Словарные упражнения** - перевод слов, синонимы, примеры использования
- ✍️ **Эссе и сочинения** - структура, проверка, советы по написанию
- 🔄 **Упражнения на перевод** - перевод с объяснением и проверкой
- 📝 **Заполнение пропусков** - помощь с fill-in-the-blanks заданиями
- 💬 **Разговорная практика** - диалоги, полезные фразы для разных ситуаций
- ✅ **Проверка текста** - поиск и объяснение ошибок
- 📖 **Объяснение правил** - понятное объяснение грамматических тем

## 🚀 Быстрый старт

### Предварительные требования

1. **Python 3.8+** установлен на вашем компьютере
2. **Tesseract OCR** для распознавания текста на изображениях
3. **FFmpeg** для обработки голосовых сообщений

### Установка зависимостей

#### Ubuntu/Debian

```bash
# Установка системных зависимостей
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-eng ffmpeg

# Установка Python зависимостей
pip install -r requirements.txt
```

#### macOS

```bash
# Установка системных зависимостей
brew install tesseract ffmpeg

# Установка Python зависимостей
pip install -r requirements.txt
```

#### Windows

1. Скачайте и установите [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki)
2. Скачайте и установите [FFmpeg](https://ffmpeg.org/download.html)
3. Добавьте пути к tesseract и ffmpeg в PATH
4. Установите Python зависимости:

```bash
pip install -r requirements.txt
```

### Настройка бота

1. **Создайте бота в Telegram:**
   - Найдите [@BotFather](https://t.me/botfather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям и получите токен бота

2. **Настройте переменные окружения:**

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Откройте `.env` и добавьте токен вашего бота:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
```

### Запуск бота

```bash
python bot.py
```

Вы увидите сообщение: `✅ Бот запущен и готов к работе!`

## 📖 Использование

### Команды бота

#### Основные команды
- `/start` - Приветствие и описание всех возможностей
- `/help` - Полное руководство по использованию

#### Команды для домашних заданий
- `/homework` - Интерактивная помощь с домашним заданием (выбор типа задания)
- `/check <текст>` - Проверить текст на ошибки
- `/explain <тема>` - Объяснить грамматическое правило

### Примеры использования

## 🔤 ПЕРЕВОДЧИК

#### 1. Перевод текста

Просто отправьте английский текст боту:

```
Hello, how are you?
```

Бот ответит:

```
🔤 Перевод:

Привет, как дела?
```

#### 2. Перевод с фото

Отправьте фото с английским текстом. Бот:
1. Распознает текст на изображении
2. Покажет распознанный текст
3. Переведет его на русский

Лучше всего работает с:
- Четкими фотографиями
- Печатным текстом
- Хорошим освещением
- Контрастным текстом

#### 3. Перевод голосовых сообщений

Запишите голосовое сообщение на английском. Бот:
1. Распознает речь
2. Покажет распознанный текст
3. Переведет на русский

**Советы для лучшего распознавания:**
- Говорите четко и не слишком быстро
- Минимизируйте фоновый шум
- Используйте короткие сообщения (до 30 секунд)

## 📚 ПОМОЩНИК С ДОМАШНИМИ ЗАДАНИЯМИ

### 1. Интерактивная помощь - /homework

Запустите команду `/homework` и выберите тип задания:

```
📚 Помощь с домашним заданием по английскому

Выберите тип задания:
✏️ Грамматика | 📖 Словарь
✍️ Эссе/Сочинение | 🔄 Упражнение на перевод
📝 Заполнить пропуски | 💬 Разговорная практика
❓ Другое задание
```

#### Примеры по типам заданий:

**✏️ Грамматика:**
```
Отправьте: Choose: She (go/goes/went) to school yesterday

Бот ответит:
✅ Ответ: went

📖 Объяснение:
Используется Past Simple, так как есть указание на прошлое (yesterday)

📝 Полное предложение:
She went to school yesterday
```

**📖 Словарь:**
```
Отправьте: Что значит magnificent?

Бот ответит:
📖 Слово: magnificent
🔤 Перевод: великолепный, величественный
```

**✍️ Эссе:**
```
Отправьте: Помоги написать эссе про мою семью

Бот даст:
- Структуру эссе (введение, основная часть, заключение)
- Полезные фразы
- Советы по написанию
```

**📝 Заполнение пропусков:**
```
Отправьте:
She ___ (go) to the park yesterday
I ___ (be) a student

Бот решит:

2. am (Present Simple)
```

**💬 Разговорная практика:**
```
Отправьте: Диалог в магазине

Бот даст:
🛍️ ДИАЛОГ В МАГАЗИНЕ

👤 Покупатель:
- How much is this? (Сколько это стоит?)
- Can I try this on? (Могу я это примерить?)
...
```

### 2. Быстрая проверка - /check

Проверьте текст на ошибки:

```
/check She go to school yesterday

Бот ответит:
⚠️ Найденные проблемы:
1. Нужно использовать Past Simple (went)
2. Не хватает знака препинания в конце

💡 Исправленный вариант:
She went to school yesterday.
```

### 3. Объяснение правил - /explain

Получите объяснение грамматической темы:

```
/explain present perfect

Бот объяснит:
📖 PRESENT PERFECT

🎯 Формула: have/has + V3
✅ Использование: ...
⏰ Маркеры времени: already, just, yet...
❌ Частые ошибки: ...
```

**Доступные темы:**
- Present Perfect
- Articles (a/an/the)
- Prepositions
- Past Simple
- Future Simple
- И другие (просто спросите!)

## 🛠️ Устранение неполадок

### Ошибка: "TELEGRAM_BOT_TOKEN not found"

**Решение:** Создайте файл `.env` и добавьте токен бота.

### Ошибка: "pytesseract is not installed"

**Решение:** Установите Tesseract OCR:
- Ubuntu/Debian: `sudo apt-get install tesseract-ocr`
- macOS: `brew install tesseract`
- Windows: Скачайте установщик с официального сайта

### Голосовые сообщения не распознаются

**Возможные причины:**
- FFmpeg не установлен или не в PATH
- Плохое качество записи
- Сильный акцент или нечеткая речь

**Решение:**
- Установите FFmpeg
- Говорите четче и медленнее
- Уменьшите фоновый шум

### Текст на фото не распознается

**Возможные причины:**
- Плохое качество изображения
- Рукописный текст (OCR работает лучше с печатным)
- Низкий контраст

**Решение:**
- Используйте более четкие фотографии
- Улучшите освещение
- Увеличьте контраст текста
