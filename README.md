# 🤖 Telegram Бот-Переводчик (English → Russian)

Быстрый и точный бот-переводчик с английского на русский язык с поддержкой текста, изображений и голосовых сообщений.

## ✨ Возможности

- 📝 **Текстовый перевод** - мгновенный перевод текстовых сообщений
- 📷 **Перевод с фото** - распознавание текста (OCR) на изображениях и перевод
- 🎤 **Перевод голосовых** - распознавание речи из голосовых сообщений и перевод
- ⚡ **Быстрая работа** - оптимизирован для максимальной скорости
- 🎯 **Точный перевод** - использует Google Translate API

## 🚀 Быстрый старт

### Предварительные требования

1. **Python 3.8+** установлен на вашем компьютере
2. **Tesseract OCR** для распознавания текста на изображениях
3. **FFmpeg** для обработки голосовых сообщений

### Установка зависимостей

#### Ubuntu/Debian

```bash
# Установка системных зависимостей
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-eng ffmpeg

# Установка Python зависимостей
pip install -r requirements.txt
```

#### macOS

```bash
# Установка системных зависимостей
brew install tesseract ffmpeg

# Установка Python зависимостей
pip install -r requirements.txt
```

#### Windows

1. Скачайте и установите [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki)
2. Скачайте и установите [FFmpeg](https://ffmpeg.org/download.html)
3. Добавьте пути к tesseract и ffmpeg в PATH
4. Установите Python зависимости:

```bash
pip install -r requirements.txt
```

### Настройка бота

1. **Создайте бота в Telegram:**
   - Найдите [@BotFather](https://t.me/botfather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям и получите токен бота

2. **Настройте переменные окружения:**

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Откройте `.env` и добавьте токен вашего бота:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
```

### Запуск бота

```bash
python bot.py
```

Вы увидите сообщение: `✅ Бот запущен и готов к работе!`

## 📖 Использование

### Команды бота

- `/start` - Приветствие и описание возможностей
- `/help` - Справка по использованию

### Примеры использования

#### 1. Перевод текста

Просто отправьте английский текст боту:

```
Hello, how are you?
```

Бот ответит:

```
🔤 Перевод:

Привет, как дела?
```

#### 2. Перевод с фото

Отправьте фото с английским текстом. Бот:
1. Распознает текст на изображении
2. Покажет распознанный текст
3. Переведет его на русский

Лучше всего работает с:
- Четкими фотографиями
- Печатным текстом
- Хорошим освещением
- Контрастным текстом

#### 3. Перевод голосовых сообщений

Запишите голосовое сообщение на английском. Бот:
1. Распознает речь
2. Покажет распознанный текст
3. Переведет на русский

**Советы для лучшего распознавания:**
- Говорите четко и не слишком быстро
- Минимизируйте фоновый шум
- Используйте короткие сообщения (до 30 секунд)

## 🔧 Технические детали

### Используемые библиотеки

- **python-telegram-bot** - взаимодействие с Telegram API
- **deep-translator** - перевод через Google Translate
- **pytesseract** - OCR (распознавание текста на изображениях)
- **SpeechRecognition** - распознавание речи
- **pydub** - обработка аудио
- **Pillow** - обработка изображений

### Архитектура

```
bot.py                  # Основной файл бота
├── start()            # Команда /start
├── help_command()     # Команда /help
├── translate_text()   # Перевод текстовых сообщений
├── translate_photo()  # OCR и перевод изображений
└── translate_voice()  # Распознавание и перевод голоса
```

### Логирование

Бот ведет подробные логи всех операций:
- Обрабатываемые сообщения
- Ошибки и исключения
- Статус операций

Логи выводятся в консоль с временными метками.

## 🛠️ Устранение неполадок

### Ошибка: "TELEGRAM_BOT_TOKEN not found"

**Решение:** Создайте файл `.env` и добавьте токен бота.

### Ошибка: "pytesseract is not installed"

**Решение:** Установите Tesseract OCR:
- Ubuntu/Debian: `sudo apt-get install tesseract-ocr`
- macOS: `brew install tesseract`
- Windows: Скачайте установщик с официального сайта

### Голосовые сообщения не распознаются

**Возможные причины:**
- FFmpeg не установлен или не в PATH
- Плохое качество записи
- Сильный акцент или нечеткая речь

**Решение:**
- Установите FFmpeg
- Говорите четче и медленнее
- Уменьшите фоновый шум

### Текст на фото не распознается

**Возможные причины:**
- Плохое качество изображения
- Рукописный текст (OCR работает лучше с печатным)
- Низкий контраст

**Решение:**
- Используйте более четкие фотографии
- Улучшите освещение
- Увеличьте контраст текста
